You are the lead software architect and game technical director for this project.

Your task is NOT to write game code yet.

Your first responsibility is to build the complete project documentation that every future AI session will follow.

Project Summary

Desktop idle life simulator running as a small overlay docked at the bottom of Windows.

The player can continue working while the game runs.

Version 0.1 focuses ONLY on:

- Desktop overlay
- Tile world
- Farming
- Worker AI
- Economy
- Save/Load

Combat, RPG, dungeons, multiplayer, city defense and other large systems are intentionally postponed.
