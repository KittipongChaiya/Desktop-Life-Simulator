Before starting Phase 02, implement a dedicated "Developer Infrastructure" milestone (Phase 01.5). This phase must add development and debugging capabilities only. Do NOT implement gameplay features.

Objectives

Build long-term developer tools that will remain available throughout the lifetime of the project.

Deliverables

1. Debug Overlay (F3)

Implement a lightweight runtime debug overlay that can be toggled with F3.

Display at minimum:

- FPS
- Simulation Tick
- UPS (simulation updates/sec)
- Frame Time
- Memory Usage
- Active Entities
- Loaded Chunks
- Visible Tiles
- Dirty Regions
- Camera Position
- Mouse Tile Coordinates
- Current Game Time

The overlay must have negligible performance impact when hidden.

---

2. Developer Console (F1)

Implement an in-game developer console.

Requirements:

- Command history
- Auto-complete
- Command registration API
- Structured command output
- Error reporting

Provide built-in commands including:

help
clear
version
fps
reload
spawn
teleport
time
money
tick
pause
resume

Gameplay-specific commands may initially return "Not implemented" but the command infrastructure must be complete and extensible.

---

3. Runtime Profiler

Implement lightweight profiling for:

Simulation
Rendering
React UI
Asset Loading
Save/Load

Display timings in the debug overlay.

Support future expansion without modifying existing profiler code.

---

4. World Inspector

Implement an inspection mode.

When enabled:

- Hovering a tile displays all known data.
- Clicking an entity displays all registered components/properties.
- Unknown values should be shown as "Unavailable" instead of causing errors.

This inspector must automatically support future entity types.

---

5. Asset Hot Reload

Implement development-only hot reloading for assets.

Changing:

- textures
- sprite sheets
- tile maps
- UI images

should update without restarting the application whenever possible.

Production builds must disable this functionality.

---

6. Logging System

Implement a centralized logger.

Support:

TRACE
DEBUG
INFO
WARN
ERROR

Requirements:

- timestamps
- subsystem names
- optional file logging
- colorized console output
- configurable log level

No direct console.log() outside the logger.

---

7. Feature Flags

Create a feature flag system.

Example:

FEATURE_DEBUG
FEATURE_PROFILER
FEATURE_CONSOLE
FEATURE_INSPECTOR

The project must be able to compile with debug features disabled.

---

8. Development Architecture

All developer tooling must be isolated from gameplay systems.

Developer tools must never introduce circular dependencies.

Game systems must never depend on debug infrastructure.

---

Testing

Provide automated tests where appropriate.

Add manual verification checklist.

Demonstrate every tool with screenshots or recorded outputs where possible.

Update all relevant documentation.

Commit as one atomic commit.

Do not begin Phase 02 until Phase 01.5 is fully complete and verified.
