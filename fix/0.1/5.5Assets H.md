Feature Integration Rules

Every future gameplay feature must answer the following questions before implementation.

Which gameplay loop does it improve?

Which existing system does it connect to?

What new player decision does it create?

Does it increase meaningful progression?

Can it be automated later?

Does it respect the player's time?

Does it introduce unnecessary complexity?

Does it create new resource sinks?

Does it strengthen the game's identity?

==================================================
Loop Validation Checklist

Before implementing any new feature, future AI sessions must verify

The feature belongs to an existing gameplay loop.

The feature connects to at least one existing system.

The feature has meaningful rewards.

The feature creates interesting player decisions.

The feature avoids repetitive busywork.

The feature maintains game balance.

The feature can scale into future versions.

The feature does not invalidate previous gameplay systems.

==================================================
Future Expansion Strategy

Explain how future gameplay systems should be added.

Prefer extending existing loops instead of creating isolated mechanics.

Prefer deeper interactions over additional currencies.

Prefer meaningful progression over larger numbers.

Future systems should naturally connect to farming, economy, crafting, workers and the living world.
