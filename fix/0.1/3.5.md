Phase-03 is complete. Do NOT begin workers, inventory, economy, buildings, NPCs, weather, or rendering improvements.

Begin Phase-03.5: Gameplay Command Foundation.

This phase establishes the interaction architecture that every future gameplay system (player, worker AI, automation, tutorials, multiplayer, replay) will share.

==================================================
Objectives
==================================================

Before implementation, determine whether the command architecture represents a long-term architectural decision.

If justified, create:

docs/decisions/ADR-010-command-model.md

Otherwise extend an existing ADR and explain why.

==================================================
ADR-010 should define
==================================================

- Commands represent player or system intent.
- Commands are the only public write API into the simulation.
- World state is never mutated directly outside command execution.
- Validation rules.
- Command lifecycle.
- Success vs rejection semantics.
- Event publication after successful execution only.
- Deterministic execution.
- Replay compatibility.
- Automation compatibility.
- Worker AI compatibility.
- Future multiplayer compatibility.
- Error handling philosophy.
- Testing strategy.

Include sequence diagrams.

==================================================
Implementation
==================================================

Do NOT add gameplay features.

Strengthen the command framework.

Implement:

CommandDispatcher

CommandResult

ValidationResult

CommandContext

CommandMetadata

Support:

dispatch()

validation

execution

post-success event publication

command rejection

No reflection.

No runtime discovery.

No global mutable state.

==================================================
Architecture Constraints
==================================================

No direct world mutation outside commands.

No gameplay system may bypass the dispatcher.

Future Worker AI must be able to issue exactly the same commands as the player.

Future replay must be able to serialize commands without special cases.

Future multiplayer should require no alternative gameplay path.
