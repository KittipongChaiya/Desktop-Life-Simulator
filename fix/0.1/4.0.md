==================================================
Problem Statement
==================================================

The project is transitioning from simulation-only gameplay to persistent resources.

Future systems will include:

- Crops
- Inventory
- Worker carrying
- Storage
- Buildings
- Crafting
- Economy
- Trading
- Dungeon loot
- Enemy drops

A single architectural model should govern how every resource enters, moves through, and leaves the world.

Avoid creating separate resource rules for different gameplay systems.

Can resources be carried?

Can resources be transferred?
