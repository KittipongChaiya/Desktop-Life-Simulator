==================================================
Phase 01.8 — Desktop Companion Features
==================================================

Objective

Implement the core desktop companion functionality that defines the identity of this project.

These are NOT gameplay systems.

They are platform-level overlay features that allow the game to comfortably coexist with normal desktop work.

The implementation must integrate cleanly into the existing architecture without introducing gameplay dependencies.

==================================================
Guiding Principles
==================================================

Desktop-first.

Non-intrusive.

Instant response.

Minimal CPU overhead.

No simulation impact.

No rendering regressions.

No platform logic inside simulation.

Maintain all existing architecture rules.

Simulation must remain completely unaware of these features.

==================================================
Features
==================================================

Implement only the following features.

No additional desktop features.

---

1. Transparency Slider

---

Allow changing window opacity.

Requirements

Range:

30%

to

100%

Default:

100%

Slider step:

5%

Opacity changes immediately.

Persist the value.

Loading a save must NOT affect opacity.

Opacity belongs to application settings, not game save.

UI should display the current percentage.

================================================== 2. Quick Hide
==================================================

Global Hotkey

F10

Behavior

Immediately hide the overlay window.

Press F10 again to restore it.

Requirements

Restore previous position.

Restore previous opacity.

Restore previous state.

Response should feel instantaneous.

Simulation continues running while hidden.

Do not pause the game.

================================================== 3. Click Through
==================================================

Global Hotkey

Ctrl + Shift + C

Toggle:

Interactive Mode

↓

Click Through Mode

When enabled

Mouse clicks pass directly through the window.

Keyboard shortcuts continue functioning.

Overlay remains visible.

Mouse interaction is ignored.

Press the shortcut again to return to Interactive Mode.

Display a small temporary notification indicating the current mode.

================================================== 4. Always On Bottom
==================================================

The game window should always remain behind normal application windows.

Requirements

VSCode

Browser

Explorer

Terminal

Office applications

should always appear above the game.

The game should never steal focus unnecessarily.

Maintain desktop companion behavior.

================================================== 5. Work Mode
==================================================

Global Hotkey

F11

Toggle:

Normal Mode

↓

Work Mode

Purpose

Reduce distraction while keeping the simulation alive.

Work Mode should:

Reduce opacity to 25%.

Hide all HUD panels.

Hide inventory.

Hide worker panels.

Hide notifications.

Hide debug overlays.

Hide selection outlines.

Disable non-essential animations.

Keep only:

World

Workers

Crops

Buildings

Simulation continues normally.

Economy continues normally.

Workers continue normally.

Press F11 again to restore the previous state.

==================================================
Architecture
==================================================

Create a platform service responsible for desktop companion behavior.

Simulation must never directly reference:

Opacity

Window APIs

Electron window

Global shortcuts

Platform services communicate through clearly defined interfaces.

Maintain dependency boundaries.

==================================================
Persistence
==================================================

Desktop settings are application preferences.

NOT save-game data.

Persist:

Opacity

Work Mode preference (last state)

Window position if already supported

Do NOT store:

Current hidden state

Current click-through state

Those should reset to default when launching.

==================================================
User Interface
==================================================

Add a Desktop Companion section in Settings.

Include:

Opacity Slider

Current Opacity %

Shortcut Reference

F11 — Work Mode

F10 — Quick Hide

Ctrl+Shift+C — Click Through

Keep the interface minimal.

==================================================
Notifications
==================================================

Display a brief toast when toggling:

Work Mode

Click Through

Quick Hide restore

Notifications disappear automatically.

==================================================
Performance
==================================================

Desktop features must have effectively zero simulation cost.

No unnecessary redraws.

No polling loops.

Prefer event-driven implementation.

Maintain render-on-demand.

==================================================
Acceptance Criteria
==================================================

✓ Opacity changes instantly.

✓ Opacity persists between launches.

✓ F10 hides/restores the window.

✓ Ctrl+Shift+C toggles click-through.

✓ F11 toggles Work Mode.

✓ Always On Bottom works correctly.

✓ Simulation continues while hidden.

✓ No gameplay regressions.

✓ No architecture violations.

✓ No simulation awareness of platform features.

✓ All existing tests pass.

Always On Top

Window resizing

Streaming mode

Screenshot mode

Presentation mode

Auto-hide

Focus detection

Idle detection

Additional hotkeys
