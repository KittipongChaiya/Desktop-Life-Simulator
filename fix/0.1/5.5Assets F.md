==================================================

Create the master content design rules.

This document defines how every future gameplay feature must be designed.

The objective is to prevent feature creep, inconsistent mechanics and unnecessary complexity.

Include principles such as:

Every new feature must improve an existing gameplay loop.

Avoid isolated mechanics.

All systems should interact with at least one other system.

Every item must have a gameplay purpose.

Every building should solve a player problem.

Every resource should have multiple uses.

Progression should feel rewarding.

Automation should be earned.

Grinding should never become mandatory.

Respect the player's time.

No pay-to-win design philosophy.

No artificial waiting mechanics.

No meaningless collectibles.

No duplicate systems.

Avoid excessive currencies.

Avoid feature bloat.

Prefer depth over quantity.

Prefer systemic gameplay over scripted gameplay.

Future RPG systems must integrate naturally with farming, economy and crafting.

Future combat must strengthen existing systems rather than replacing them.

Future multiplayer must never invalidate single-player gameplay.

Future content should reuse existing mechanics whenever possible.

Include review checklists for future AI before implementing any new feature.
